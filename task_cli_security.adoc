= Sichern Sie eine ONTAP Select Bereitstellung
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Eine ONTAP Select Implementierung kann abgesichert werden, indem bei Bedarf das Kennwort für das Administrator-Konto der Deploy-virtuellen Maschine über die Befehlszeile geändert wird.

.Schritte
. Melden Sie sich mit dem Administratorkonto bei der Deploy-Utility-CLI an.
. Ändern Sie das Passwort:
`password modify`
. Reagieren Sie auf alle Aufforderungen entsprechend Ihrer Umgebung.
