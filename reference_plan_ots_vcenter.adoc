= ONTAP Select VMware vCenter Server auf ESXi
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Sie müssen ein vCenter-Serverkonto definieren und es einer Rolle zuordnen, die die erforderlichen administrativen Berechtigungen enthält.


NOTE: Sie benötigen außerdem den vollqualifizierten Domainnamen oder die IP-Adresse des vCenter Servers, der die ESXi-Hypervisor-Hosts verwaltet, auf denen ONTAP Select bereitgestellt ist.
